## 1. 확정된 결정 사항

| 질문 | 결정 |
|---|---|
| 로드아웃 | 무기(검/창/둔기/활) 1개 + 마법(원소/암흑/신성/정신) 1개, 총 2개 동시 장착 |
| 평타(자동 공격) | **무기만** 평타. 마법은 평타에 관여하지 않고 스킬 전용 |
| 기존 마스터리 패시브 특성 | 그대로 유지(공속 증가, 관통 피해, 기절, 치명타, 화상, 흡혈, 추가회복, 약화) + 스킬은 별도 계층으로 추가 |
| 스킬 해금 방식 | 숙련도 레벨 5(1번째), 15(2번째)에 도달 시 후보 중 하나를 선택 |
| 스킬 후보 수 | 타입당 4개 후보 중 2개를 선택(진짜 선택지, 남은 후보는 영구히 못 얻음) |
| 장착 스킬 수 | 무기 2개 + 마법 2개 = 총 4개, 전투화면 하단 4슬롯에 표시 |
| 시전 방식 | "자동 시전" 토글 ON = 쿨다운마다 자동 발동 / OFF = 클릭해야 발동(쿨다운 되어 있어야 가능) |
| 마법 숙련도 성장 | 평타에 안 쓰이므로, 마법 스킬을 시전할 때마다 해당 마법 숙련도 사용 횟수 증가 |

**마법 4종 컨셉** (이전에 확정, 스킬 설계에 반영됨):
- 원소마법: 직접 타격형 - 느린 캐스팅/긴 쿨다운, 강력한 한방
- 암흑마법: DOT(지속 피해) 위주
- 신성마법: 힐/방어력 향상 등 방어적 스킬
- 정신마법: 흡혈, 정신지배(행동불능), CC

**주의**: 현재 `masteryConfig.js`의 패시브 트레잇 배정이 이 컨셉과 어긋남(원소=burnDot, 암흑=lifesteal, 정신=weakenChance). 스킬 시스템 작업 시 함께 재배정 검토.

## 2. 스킬 카탈로그 (8타입 × 4후보 = 32개, 임시 수치)

데미지 배수는 해당 타입의 기본 공격력(물리 or 마법) 1회분을 1.0으로 보는 배수. 밸런싱은 나중(TODO #3).

### 검 (물리)
1. **연속 베기** - 2연타(각 100%), 쿨다운 4s
2. **일섬** - 강한 단일타(300%), 쿨다운 12s
3. **칼날 폭풍** - 3연타(각 60%), 쿨다운 8s
4. **약점 가격** - 단일타(120%) + 3초간 적 받는피해 +20%, 쿨다운 10s

### 창 (물리)
1. **관통 찌르기** - 단일타(250%), 쿨다운 10s
2. **회전창** - 4연타(각 50%), 쿨다운 9s
3. **창격 연쇄** - 단일타(150%) + DOT(총 150%, 3초), 쿨다운 8s
4. **필살 찌르기** - 단일타(400%), 쿨다운 20s

### 둔기 (물리)
1. **강타** - 단일타(200%) + 전방 기절, 쿨다운 10s
2. **대지 강타** - 단일타(150%) + 스택된 몬스터 전체 기절, 쿨다운 14s
3. **분쇄** - 단일타(100%) + 4초간 적 받는피해 +15%, 쿨다운 8s
4. **연타** - 3연타(각 70%), 쿨다운 9s

### 활 (물리)
1. **조준 사격** - 단일타(150%) 확정 치명타, 쿨다운 9s
2. **연사** - 3연타(각 60%), 쿨다운 7s
3. **관통 사격** - 단일타(220%), 쿨다운 11s
4. **독화살** - 단일타(100%) + DOT(총 200%, 4초), 쿨다운 10s

### 원소마법
1. **파이어볼** - 단일타(350%), 쿨다운 15s
2. **썬더 스트라이크** - 단일타(180%) + 전방 기절, 쿨다운 11s
3. **아이스 스파이크** - 단일타(220%) + 적의 다음 공격 무효화, 쿨다운 12s
4. **메테오** - 단일타(450%), 쿨다운 20s

### 암흑마법
1. **저주** - DOT(총 300%, 6초), 쿨다운 10s
2. **부패** - DOT(총 200%, 8초) + 8초간 적 받는피해 +15%, 쿨다운 9s
3. **암흑구체** - 단일타(150%) + DOT(총 150%, 4초), 쿨다운 11s
4. **죽음의 표식** - DOT(총 500%, 10초), 쿨다운 16s

### 신성마법
1. **치유의 빛** - 최대체력 20% 즉시 회복, 쿨다운 10s
2. **축복** - 최대체력 10% 회복 + 3초간 받는피해 -30%, 쿨다운 12s
3. **정화** - 최대체력 15% 회복, 쿨다운 9s
4. **대회복** - 최대체력 40% 회복, 쿨다운 16s

### 정신마법
1. **정신 흡수** - 단일타(150%) + 가한 피해의 30% 흡혈, 쿨다운 9s
2. **지배** - 전방 몬스터 장시간 행동불능(기절의 강화판), 쿨다운 14s
3. **공포** - 단일타(120%) + 적의 다음 공격 무효화, 쿨다운 10s
4. **영혼 착취** - 단일타(200%) + 가한 피해의 50% 흡혈, 쿨다운 12s

## 3. 이펙트 프리미티브 (구현 시 재사용할 공용 단위)

스킬마다 `effects: [...]` 배열을 순서대로 실행하는 방식으로 설계(하나의 스킬이 데미지+부가효과를 조합 가능):

- `damage` - 단일 타격 (multiplier, guaranteedCrit 옵션)
- `multiHit` - 다단 히트 (hits, multiplierEach)
- `dot` - 지속피해 (totalMultiplier, durationMs) - 기존 화상 트레잇과 같은 슬롯(`combat.dotRemainingMs`/`dotDamagePerSec`) 재사용, 즉 동시에 여러 DOT가 겹치진 않고 최신 것으로 덮어씀(기존 시스템과 동일한 단순화)
- `heal` - 즉시 회복 (pctMaxHp)
- `stunFront` / `stunAll` - 전방 1마리 또는 스택된 몬스터 전체 기절 (기존 `stunChance` 트레잇과 동일한 방식: `monsterAttackElapsedMs`를 되돌림)
- `debuffEnemyDamageTaken` - 몬스터가 받는 피해 증가 (bonusPct, durationMs) - **신규 상태 필드** 필요(`combat.enemyDamageTakenBonusPct`/`enemyDamageTakenRemainingMs`), `damageMonster()` 내부에서 승수로 적용
- `buffSelfDamageReduction` - 플레이어가 받는 피해 감소 (pct, durationMs) - **신규 상태 필드** 필요(`combat.playerDamageReductionPct`/`playerDamageReductionRemainingMs`), 몬스터의 공격 피해 계산 시 적용
- `nullifyNextEnemyHit` - 기존 `monsterNextHitReductionPct` 필드 재사용 (1.0 = 다음 1회 완전 무효화)
- `lifesteal` - 같은 스킬 내에서 앞서 실행된 `damage`/`multiHit`가 낸 총 피해량 기준으로 회복

이 구조면 32개 스킬을 개별 함수 없이 데이터(설정)만으로 표현 가능.

## 4. 상태 스키마 변경 (v5 → v6 세이브 마이그레이션 필요)

```
state.combat:
  - activeStyleId 제거
  - activeWeaponId (신규, 기본값 'sword')
  - activeMagicId (신규, 기본값 'elemental')
  - skillCooldowns: {} (신규, { [skillId]: remainingMs })
  - autoCastSkills: true (신규, 자동 시전 토글)
  - enemyDamageTakenBonusPct: 0, enemyDamageTakenRemainingMs: 0 (신규)
  - playerDamageReductionPct: 0, playerDamageReductionRemainingMs: 0 (신규)

state.character:
  - skills: { [masteryId]: { unlockedSkillIds: [] } } (신규, 8개 타입 전부 빈 배열로 초기화)
```

마이그레이션 시 기존 `activeStyleId`가 무기였으면 `activeWeaponId`에, 마법이었으면 `activeMagicId`에 넣고 나머지 슬롯은 기본값으로 채우면 됨.

## 5. 전투 로직 변경 요지 (`combatSystem.js`)

- `getActiveStyleDef` → `getWeaponDef`/`getMagicDef`로 분리. 평타 계산(`getBaseAttackDamage`, `applyStyleTrait`, `getAttackIntervalMs`, 숙련도 사용 횟수 증가)은 전부 무기 기준으로만 실행.
- `castSkill(state, skillId, onEvent)`: 장착된 스킬인지 + 쿨다운 확인 → 쿨다운 리셋 → 해당 타입 숙련도 사용 횟수 증가 → `resolveSkillEffects` 실행.
- `advanceCombat` 틱마다: 버프/디버프 지속시간 감소 → 무기 평타 → 스킬 쿨다운 감소 + (자동시전 켜져있으면) 준비된 스킬 자동 발동 → 힐 반영 → 몬스터 반격(플레이어 피해감소 적용) → 스택 몬스터 반격 → 스폰.
- `damageMonster`에 `enemyDamageTakenBonusPct` 승수 적용.
- `getExpectedPlayerDps`(오프라인 정산용)는 무기 평타 기준으로만 유지 - 스킬로 인한 추가 DPS는 계산에 넣지 않음(보수적으로 안전한 방향이라 의도적으로 단순화).

## 6. UI 변경 요지

- 전투화면 하단 control-bar: 지금의 목업 🔥🛡️🏹 버튼 3개 + 자동토글을 **실제 장착 스킬 4개 + 자동토글**로 교체. 각 슬롯에 쿨다운 표시(예: 원형 오버레이 또는 숫자 카운트다운), 쿨다운 중엔 클릭 비활성.
- 스킬 선택 모달: 숙련도 레벨이 5/15에 도달하면 해당 타입의 미획득 후보 목록을 보여주고 하나를 고르게 함 (`modal.js`의 `renderModal` 패턴 재사용).
- 무기/마법 개별 선택: 2열 숙련도 패널의 각 행이 이미 클릭 가능한 버튼이므로, 클릭 시 그 행의 category(physical/magic)에 따라 `activeWeaponId` 또는 `activeMagicId`를 갱신 - 무기 1개 + 마법 1개가 동시에 강조 표시됨(기존엔 전역 1개만 강조).

## 7. 열린 질문 (다음 세션에서 확인)

- DOT가 단일 슬롯이라 여러 DOT 스킬을 연속 시전하면 이전 것이 덮어써짐 - 지금은 기존 화상 트레잇도 같은 제약이라 일관되지만, 스킬이 늘어나면 아쉬울 수 있음. 다중 DOT 슬롯으로 확장할지는 추후 판단.
- 스킬 선택은 영구적(되돌릴 수 없음)으로 설계했는데, 이걸 재선택(리스펙) 가능하게 할지는 아직 미정.
- 자동 시전 시 4개 스킬이 쿨다운 준비되는 즉시 전부 동시에 나가는데, 이게 시각적으로 너무 한꺼번에 몰릴 수 있음 - 약간의 발동 텀을 둘지 고려.
