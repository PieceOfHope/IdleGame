- **확인된 의도**: 1열 = GUI+전투로그, 2열 = 사용자가 선택하지 않아도 자동으로 오르는 것(숙련도), 3열 = 사용자가 직접 선택/배분하는 것(스탯 포인트, 영구강화, 무기·마법 로드아웃).

- 다음 세션에서 실제 그리드 restructure 진행 예정.
