## 🧬 시스템 개편 (규모가 큰 작업들)

### 6. ~~디아블로2 스타일 스탯 포인트 분배~~ (구현 완료)
- 요청: 캐릭터 레벨업 시 스탯 포인트 5개 지급 → 힘/민첩성/지력/체력/회복력에 자유 배분, 재분배(내리기)도 가능. 모든 스탯은 0부터 시작, 음수 불가.
- 설계: 신규 `totalExp`(몬스터 처치 시 `expReward` 획득) → `levelFromUsage`(masteryCurve.js 재사용)로 캐릭터 레벨 산출 → 레벨 × 5 = 누적 지급 포인트. 힘/민첩성/지력/체력/회복력은 "숙련도"가 아니라 "스탯"이므로 사용 횟수 기반 자동 성장을 완전히 제거하고 포인트 배분으로만 성장(무기/마법 8종 숙련도는 기존 방식 그대로 유지).
- 스탯 1포인트당 효과(룰): 힘 = 물리 공격력 +2%, 지력 = 마법 공격력 +2%, 민첩성 = 공격 속도 증가(하한 있음), 체력 = 최대 체력 +4, 회복력 = 초당 회복 +0.05. `characterConfig.js`의 `STAT_CONFIG[].hint`에 명시, 스탯 행에 마우스 올리면 툴팁으로 표시됨.
- 파생 스탯 표시(물리 공격력/마법 공격력/공격 속도/최대 체력/체력 회복)를 3열에 별도 패널로 추가 - `characterSystem.js`의 `getStatPreview()`.
- "Lv." 라벨은 스탯에 안 어울려서 제거 - 이제 스탯 행에는 숫자만 표시.
- 세이브 v5로 마이그레이션, v4 이하 세이브는 스탯 진행도를 이어받지 않고 0부터 시작(#9 참고).
- 레벨 곡선 수치(CHARACTER_LEVEL_COEFFICIENT=0.5, baseExpReward=3, expGrowth=1.1)는 임시값 - #3 밸런싱 때 같이 조정 필요.

### 7. 무기 + 마법 조합(로드아웃) 시스템
- 요청: 무기 종류 1개 + 마법 종류 1개를 동시에 선택해서 조합, 선택한 것들의 숙련도만 계속 성장.
- 현재 구조: `activeStyleId` 하나만 선택 가능(무기/마법 구분 없이 8종 중 1개 - `combatSystem.js`).
- **내 의견**: `MASTERY_CONFIG`에 이미 `category`(physical/magic) 필드가 있어서, "physical 슬롯 1개 + magic 슬롯 1개"의 이중 슬롯 구조로 바꾸는 게 자연스러움. 다만 공격 판정을 어떻게 할지(매 공격마다 무기+마법 데미지 동시 적용? 번갈아 발동?) 전투 로직 설계가 필요.
- **마법 4종 컨셉(확정)**:
  - 원소마법: 직접 타격형 - 캐스팅이 느리거나 쿨타임이 길지만 강력한 한방.
  - 암흑마법: DOT(지속 피해) 위주.
  - 신성마법: 힐/방어력 향상 등 방어적 스킬 위주.
  - 정신마법: 특수계 - 흡혈, 몬스터 정신지배, 행동불능(CC) 등.
  - **주의**: 지금 `masteryConfig.js`의 트레잇 배정이 이 컨셉과 어긋남 - 원소마법이 오히려 `burnDot`(DOT), 암흑마법이 `lifesteal`(흡혈), 정신마법이 `weakenChance`(약화)로 되어 있음. 로드아웃 시스템 작업할 때 트레잇을 위 컨셉에 맞게 재배정 필요(대략 원소↔암흑을 맞바꾸고, 정신마법에 흡혈/CC 계열 트레잇을 새로 부여하는 방향).
